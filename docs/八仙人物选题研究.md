## 一、版本辨析：先查证「八仙」到底指哪部动画片

用户问「了解八仙这个动画片不、熟悉它的动画风格不」时，第一件事是查证，避免把电视剧、木偶片、不同年代版本混为一谈。两轮检索 + 交叉核实后的结论：

| 版本 | 性质 | 造型 / 美术 | 可信度 |
|---|---|---|---|
| **1988 上美影《八仙与跳蚤》** | 詹同导演，约 10 分钟剪纸动画短片，取材八仙过海 | 造型设计高马得 / 陈汝勤；第二稿糅合**昆曲人物身段**；民间**单色剪纸**，接近山西剪纸；**每人一个代表色**（何仙姑粉、曹国舅橘、蓝采和紫等） | 高，多源可交叉 |
| 2026 院线《八仙!》 | 牟正洋导演，青绿新国风 | 宋元青绿山水 + 汉代壁画鱼拉辇车 + 年画五色 / 刺绣 / 永乐宫壁画 + 琉璃渐变 / 镭射光泽；「一人一韵」（吕洞宾鹤纹、钟离权兽纹、何仙姑荷花刺绣），多人同框靠剪影区分 | 高 |
| 2007 齐鲁音像《八仙过海》13 集 / 2019 金鹰卡通《八仙过海》10 集 | 传统神话科普 / 少儿国风 | 常规电视动画 | 中 |
| 网传「1985 上美影《八仙过海》剪纸动画」「1997 王刚版 / 主演陈红」 | 营销稿拼凑 | — | **误传**，不采用 |

**结论：A 方向锁定 1988 剪纸民俗语言的形式机制，不复刻任何具体造型、图案或角色设计。**

## 二、风格位判定：为什么是剪纸

已占风格位：三国 `17_ink` 水墨写意 / 水浒 版画线描 / 红楼 `10_nouveau` 慕夏 + `20_dunhuang` 收口 / 西游 `20_dunhuang` 敦煌重彩 / 动画复刻 `34_shadowpuppet` 中国皮影 / 爱心萌可 `33_rubberhose` 橡皮管卡通。

本地技能库 36 张风格卡里**没有**「中国民俗剪纸 / 木版年画 / 青绿山水」专卡；最接近的是 `34_shadowpuppet`（镂刻 + 铆钉 + 10fps 步进，但半透明牛皮 + 操杆）、`30_matisse`（剪刀折线 + 钉纸投影，但属西方剪纸）、`20_dunhuang`（已被西游占用）。**「民俗套色剪纸」仍是空位**。

三条路线与取舍：

| 路线 | 内容 | 取舍 |
|---|---|---|
| **A（用户选定）** | 1988 剪纸民俗风八仙人物系列，新建 `37_papercut` 风格卡，先出铁拐李样张钉风格 | ✅ 亮窗纸 / 朱红纸片 / 硬边剪口，与既有四个系列全部拉开；全代码平面路线可复用 |

## 三、剪纸语法：把「剪 → 刻 → 贴 → 揭」写成渲染器

| 形式元素 | 渲染器 | 能动方式 |
|---|---|---|
| 剪刀折线 / 锯齿剪口 | `jag(pts, amp, seed, per)` 每条边插入交替法向偏移中点 | 纸片随风整体轻摆，剪口本身不动 |
| 纸片平涂 + 贴片投影 | `paper(g, pts, col, opt)`：偏移 8/10px 暗影 → 平涂 → 纸白毛边 | 按 index 错峰「贴上」显影 |
| 镂空刻纹 | `carveLine / carveMoon / carveSaw`，用**窗纸色**画在纸片上＝刻穿 | 刻纹逐格点亮、窗花环反向转 |
| 窗纸舞台 | `stage()`：米黄渐变窗纸 + 纸纤维（只在背景）+ 窗棂横带 + 四角剪花 + 侧栏花签 / 判词 / 朱红钤印 | 透光径向脉动、角花转、纸屑 12fps 飘落 |
| 分件铰接 + 一人一专色 | 肩 / 肘 / 膝铆钉；`PAL` 八张色板只换 `main/mainDk/mainHi` | 关节按 pose 分件旋转；法宝剪影随手腕动 |

与相近风格的分界：**皮影**是半透明牛皮 + 操杆 + 幕后油灯；**马蒂斯**是西方水粉剪纸 + 海藻曲线；**敦煌**是土红地仗 + 矿物色 + 铁线描；**本风格**是亮色窗纸 + 不透明纸片 + 硬边剪口 + 民俗窗花。角色也必须过同一套材料（`paper` + `jag` + `carve`），否则读成贴上去的剪贴画。

完整配方卡见 `经验与方法/风格卡_37_papercut.md`，并已回流技能库 `references/风格配方/37_papercut.md`（INDEX 由 35 种更新为 36 种）。

  scenes/bx_series.js          → window.BX_SERIES   共享模板（镜头/匾额/前景/收印）
  scenes/bx_tight.js           → SCENES k1..k8      8 幕 × 3.8s = 30.4s 紧凑引擎
  eras_bx_sample.js            样张段落表
  eras_tieguali_v2.js          首支成片段落表
voice/
  ambience.py / build_voice_remake.py / prepare_channels_remake.py
  lines_tieguali_v2.json / 发布元数据_复刻.json
_生成_八仙配置.py / _批量渲染_紧凑版.py / _合成_系列.py / _qa_系列.py / _批量收口_系列.py

## 八、红线（写死，别再犯）

1. **`U.ss(lo,hi,x)` 是 smoothstep 阈值函数返回 0..1，不是区间插值**；要 `[a,b]` 必须 `a+(b-a)*ss(0,1,x)`。
2. 屏幕空间覆盖层（窗纸帘 / 判词纸签 / 结句底）必须在 camera `restore()` 之后画，否则两层 clip 求交吞掉。
3. **深色线画在深色块上等于没画**；镂空刻纹用窗纸色，烟 / 气按底色选朱红或纸白，线宽 ≥3.4 才能在 1100px 降采样后读出。
4. 组合道具必须补连接件（葫芦背带 / 扁担垂绳），否则读成悬空贴片。
5. 屏幕空间帘开度要按该幕前景位置定：中央有前景时开得更宽，否则会整片吞掉。
6. 8 幕紧凑版字幕占满 3.3~3.6s/幕，幕间空隙不足以反推安全无字幕点；**封面一律从同源未烧字幕无声片抽帧**（元数据 `cover_video`）。
7. 转场白名单 `organic / crossfade / dotBloom / pageTurn`；禁 `ripple`（扭竖排判词与钤印）、`radiant / lampGlow`（亮窗纸过曝）。
8. `bgKey` 必须每片唯一，否则 `P.cached` 命中别的片子的窗纸底图。
9. `U.rng(seed)` 返回函数：`const r = rng(37); r()`；当数值用会静默 NaN 让元素消失且不报错。
10. 步进帧率（12fps）只给纸屑 / 纸片颤动 / 眨眼，不整屏换帧；整屏低帧率会读成闪。
11. `eras` 的 `dur` 之和必须 = `lines.total`（转场时长已嵌入 dur，不额外叠加）；一句一幕，`t1` 对齐幕边界。
12. 做旧（纸纤维 / 污渍）只在背景，人物保护区不放剥落斑——否则读成衣服破洞。

### 关于「活气中位 5.772% < 8% 目标」的处理

8% 是红楼 V2 / 西游系列为「慕夏光环 / 敦煌矿物背光」这类**大面积连续运动**校准的软目标，不是死帧门禁。
本片是纸片平涂：可动面积天然小，k7 判词、k8 收束还刻意把运动幅降到 0.45 / 0.72。
首轮 5.179% 已 0 死帧 / 0 跳变；提过一档（窗纸透光脉动 0.045→0.10、扫光 0.13→0.19、纸屑 22→34、窗花环转速翻倍）后到 **5.772%**，画面仍干净。
**不再靠加噪点硬凑数字**：沿用西游观音 7.675% / 收口 7.841% 的判例，以「0 死帧 + 0 跳变 + 幕内可见运动链」为准，QA 判 PASS。若后续要冲 8%，正确做法是给纸片加「分件铰接摆动」（肩/肘/膝各自相位），而不是再撒纸屑。

### 12.5 新增红线（接第八节，编号 13~17）

- **⑬ 同风格批量扩片用「零回归扩展」**：新内容全放独立文件 + 一个 `has()/body()` 分派钩子；共享层只加「默认等价」的回落分支；改代码前先留基线静帧，接入后逐像素比对，不能只靠肉眼说「看着没变」。
- **⑭ 屏幕空间布局先算占位**：结句横幅、匾额、4×2 卡片、钤印共用中央窗纸，必须按 y 区间排开；末幕宁可撤匾额，也不要让文字压卡片。
- **⑮ 浅色纸片不能画在深色纸带之前**：后画的纸带会整片盖住纸白主体；背景带先画、浅色主体后画并抬到纸带上沿。
- **⑯ 一人一专色不等于群像可辨**：同框至少要有「剪影 + 头饰 + 法宝 + 专色」四件套，缺头饰就退化成同一张纸片换色。
- **⑰ 显影窗口要对齐审片帧与封面帧**：`ss` 阈值函数写成 `lo/hi` 之后必须拿 `lt = 审片秒 − 幕起点` 反算 alpha，别让关键帧停在半透明。
