# 37_papercut · 中国民俗套色剪纸（八仙人物系列）

> 2026-11-07 新建。方向来源：1988 上美影《八仙与跳蚤》的剪纸民俗语言（詹同导演，高马得 / 陈汝勤造型，
> 第二稿糅合昆曲人物身段，民间单色剪纸，每人一个代表色，接近山西剪纸）。
> **只学机制与形式元素，不复刻任何具体造型、图案或角色设计**；全部以几何路径重新绘制。
> 与 `30_matisse`（西方剪纸）、`34_shadowpuppet`（半透明牛皮 + 操杆）、`20_dunhuang`（矿物重彩 + 铁线描）
> 的区别：亮色窗纸、不透明纸片平涂、硬边剪口、镂空刻纹、贴片投影、一人一专色。

## 一句话

把「剪 → 刻 → 贴 → 揭」这个物理过程写成渲染器，画面里每一块颜色都是一张独立纸片。

## 五个最辨识度的形式元素，以及它本来会怎么动

| 形式元素 | 代码渲染器 | 能动的方式 |
|---|---|---|
| 剪刀折线 / 锯齿剪口 | `jag(pts, amp, seed, per)`：每条边插入交替法向偏移的中点 | 纸片随风整体轻摆（相位按部件 index），剪口不动 |
| 纸片平涂 + 贴片投影 | `paper(g, pts, col, opt)`：先画偏移 8/10px 的暗影，再平涂，最后一道纸白毛边 | 分片「贴上」的显影：按 index 错峰 scale/alpha 入场 |
| 镂空刻纹 | `carveLine / carveMoon / carveSaw`，用**窗纸色**画在纸片上＝刻穿 | 刻纹逐格点亮；窗花环缓慢反向转 |
| 窗纸舞台 | `stage()`：米黄渐变窗纸 + 纸纤维（只在背景）+ 窗棂横带 + 四角剪花 + 侧栏花签 / 判词 / 朱红钤印 | 窗纸透光径向脉动、角花转、纸屑 12fps 飘落 |
| 分件铰接 + 一人一专色 | 肩 / 肘 / 膝铆钉；`PAL` 八张色板只在 `main/mainDk/mainHi` 上换色 | 关节按 pose 分件旋转；法宝剪影随手腕动 |

## 管线（八仙工程）

```
engine/scenes/index.js 按 SCENE_LIBS 顺序同步加载：
  bx_common.js   → window.BX        公共层（色板/几何/jag/paper/carve/stage/curtainScreen/verdictPaper/motion）
  bx_figure.js   → window.BX_FIGURE 纸片分件铰接 rig（八组 pose）
  bx_sample.js   → SCENES s1..s3    三幕风格样张（15s）
  bx_series.js   → window.BX_SERIES 共享模板（镜头 / 匾额 / 前景 / 收印）
  bx_actors.js   → window.BX_ACTORS 第二批 7 人 rig + 各自 8 幕前景（仅第二批加载）
  bx_finale.js   → SCENES f1..f8     收口片独立层（仅收口片加载）
  bx_tight.js    → SCENES k1..k8    8 幕 × 3.8s = 30.4s 紧凑引擎
eras_<key>.js 里 window.SERIES_KEY + SCENE_LIBS + ERAS。顺序是隐式依赖，不可换。

三条链路（2026-11-07 第二批扩展）：
  首支       common → figure → series → tight
  第二批     common → figure → series → actors → tight
  收口片     common → figure → finale（f1..f8 与 k1..k8 完全隔离）
扩展采用「零回归」：actors 把 7 条 FILMS 配置 Object.assign 进 S.FILMS，
tight 的 body() 顶部 has() 命中即整幕交出；共享层色板一律写 `cfg().pal || P`，
首支分支一字不改。接入后重渲首支 8 帧逐像素全等（getbbox()=None）才放行。
```
转场白名单沿用 `organic / crossfade / dotBloom / pageTurn`；**禁 `ripple`**（逐行位移把竖排判词与钤印扭成锯齿）、
禁 `radiant / lampGlow`（亮窗纸上过曝）。签名转场可理解为「揭窗纸 / 翻纸页」。

## 角色也要过材料处理

不复用仕女 / 猴王 / 皮影骨架。铁拐李 = 蓬头虬髯（jag 墨纸）+ 佝偻破衲（朱红纸片 + 靛青补丁 + 月牙镂空）
+ 一腿直立一腿跛曲悬空 + 束腰葫芦（金口 / 红绳 / 背带连接件 / 握持的手）+ Γ 形铁拐（横把 + 左垂钩 + 金箍）。
**组合道具必须补连接件**：首轮葫芦没有背带，读成「贴在腰上的一团绿叶」，加 `gourdCord()` 后才成立。

第二批 7 人共用一套「纸片分件铰接」骨架，但头饰 / 须发 / 袍身 / 法宝 / 专色各自独立：
汉钟离双丫髻 + 袒腹 + 芭蕉扇、吕洞宾道冠 + 五绺须 + 纯阳剑、何仙姑双鬟 + 裙裾 + 荷花、
曹国舅方翅官帽 + 玉板、蓝采和乱发 + 破蓝衫 + 花篮、韩湘子儒巾 + 青衫 + 紫金箫、
张果老老叟巾 + 白须 + 渔鼓与纸驴。

**八人群像靠「剪影 + 头饰 + 法宝 + 专色」四件套区分，不靠五官，也不能只靠专色**：
收口片首轮八张卡片只换颜色，同框读成「同一张纸片换色」；补八顶独立头饰剪影后才成立。
这是风格卡原「仍可改进 ①」的实做验证结论。

## 母题小循环（每幕至少主动作 + 2 个）

主动作 = pose / 倾斜 / 镜头推近 / 前景换幕；小循环 = 窗纸透光脉动 (`sin(t*1.15)`)、窗花环反向转、
纸屑下落 (`pmod`)、飘带摆动 (`sin(t*1.15+k)`)、纸片 12fps 颤动、斜向扫光 (`pmod(t*210,1500)`)。

## 性能

窗纸底 + 纤维 + 外框 + 窗棂全部 `P.cached('bx_bg_'+bgKey)` 一次生成；`bgKey` 必须每片唯一，
否则会命中别的片子的底图。每帧只画动态层与纸片；样张静帧约 60~90ms/帧（无 GPU 逐帧 flush 的数字）。

## 踩过的坑（写死，别再犯）

1. **`U.ss(lo,hi,x)` 是 smoothstep 阈值函数返回 0..1，不是区间插值**；要 `[a,b]` 必须 `a+(b-a)*ss(0,1,x)`。
2. 屏幕空间覆盖层（窗纸帘 / 判词纸签 / 结句底）必须在 camera `restore()` 之后画，否则两层 clip 求交吞掉。
3. **深色线画在深色块上等于没画**；镂空刻纹要用窗纸色，烟/气要用朱红或纸白，视底色定。
4. 两瓣葫芦若没有明显束腰、金口、绳与背带，会读成绿团；Γ 形拐若画成一整块锯齿多边形，会读成黑团 —— 要留窗纸空隙。
5. 盘腿打坐不能只把立像缩小：必须有蒲团 + 两条交叠纸片，否则读成「站着的小一号同一张图」。
6. 空床只画一条深色横条会读成红杠；补两条床腿 + 一端纸枕才成立。
7. 窗花外圈的**大三角**会读成彩旗 / 派对拉花；换成带镂空孔的小花瓣才像民间窗花。
8. 8 幕紧凑版字幕占满 3.3~3.6s/幕，幕间空隙不足以反推安全无字幕点；封面从**同源未烧字幕无声片**抽帧。
9. `U.rng(seed)` 返回函数，用 `const r = rng(37); r()`；当数值用会静默 NaN 让元素消失且不报错。
10. **零回归扩展不能动首支分支**：新增人物用 `Object.assign(S.FILMS, CFG)` + `body()` 顶部 `has()` 分派；
    共享层每处色板都写 `cfg().pal || P`（默认分支必须逐字节等价），接入后重渲首支 8 帧逐像素比对才放行。
11. **收口片的屏幕空间布局要先算占位**：结句横幅 650..812 会把 4×2 卡片的下排整排盖住。
    解法是卡片随幕内 `q` 整体上移 130px 让位、末幕撤掉匾额、钤印移到横幅下方；横幅显影窗口再对齐审片帧。
12. **浅色纸片不能画在深色纸带之前**：纸驴是纸白色，先画驴再画山石带会被整片埋掉；
    必须先画背景带、再画浅色主体，并把主体抬到纸带上沿（y≈800 而不是 872）。
13. **一人一专色 ≠ 群像可辨**：只换颜色时八张卡片同框读成同一张纸片；
    必须补头饰剪影（蓬头 / 丫髻 / 道冠 / 双鬟 / 官帽 / 乱发 / 儒巾 / 老叟巾）。
14. **横幅显影窗口要对齐审片帧**：`ss(0.55,1.0,lt/2.6)` 在 lt=1.9 只有约 0.36 alpha，结句读不清；
    前移到 `ss(0.30,0.85,lt/1.9)`，既避开「半透明横幅压卡片」，又在 28.5s 审片帧前完全显影。
15. **首支配置生成器重跑会清空其他片元数据**：必须 merge 已有 `films` 条目，
    否则后续片的合成 / QA / 打包全部找不到 key。
16. **批量配音连续请求会撞上 TTS 瞬时故障**：串行跑到 40+ 句后，3 部在不同句子上抛 `CalledProcessError(rc=1)`，
    各留一个 `line_*.wav.mp3` 半成品残件。先手工跑一次 `--worker` 验证服务端已恢复（`rc=0`），
    再清掉明确残件、单 key 串行重试即可全绿；**不要改台词 / 调 rate / 重渲画面**（西游 `finale` 同例）。
    另：个别句子 3.37~3.38s 略超保守预算 3.29s 只是提示，幕长 3.8s 且下一句按幕边界对齐，不返工。

## 质量与仍可改进

质量 ★★★（三幕样张、首支 8 幕成片、第二批 7 支 + 收口片共 9 部全部审片 PASS：
一眼认得出民俗剪纸，角色与窗纸舞台融合，纸片分层明确）。
首支《铁拐李·借躯还魂》实测：30.4s / 8 幕 / 活气中位 **5.772%**、死帧 0 / 跳变 0 / QA PASS。
第二批沿用同一判据；**全系列 9 部已于 2026-11-08 全链路验收 ALL PASS**（27 段渲染全绿、9/9 死帧 0 / 跳变 0 / 四件套 gate=True），
人物片活气中位 5.023~5.772%、收口片 2.249%（逐格贴纸刻意收敛）。逐部数据见 `八仙人物选题研究.md` 第十二节。
**注意**：8% 活气中位是为「慕夏光环 / 敦煌矿物背光」这类大面积连续运动校准的软目标，纸片平涂风格可动面积天然小，
判词 / 收束幕还会刻意降幅；提过一档窗纸脉动 / 扫光 / 纸屑（22→34）后只从 5.179% 到 5.772%，
不靠加噪点硬凑数字。若后作要冲 8%，正确解法是给纸片加「肩 / 肘 / 膝分件铰接摆动」，而不是再撒纸屑。

**已验证（2026-11-07 第二批）**：八人同框群像的剪影辨识度做了实做验证 ——
只靠一人一专色不够，补八顶独立头饰剪影后 4×2 同框可逐一点名，见踩坑 13。
仍可改进：① 浅窗纸上细刻线在 1100px 降采样后会变淡，线宽建议 ≥3.4；
② 昆曲身段目前只有「S 形手势 / 错步」的静态形，还没有真正的水袖动作循环；
③ 七支人物片共用同一套 8 幕节奏，缘起 / 判词 / 收束幕的构图同构度偏高，
若做第三批应给不同人物换幕型（例如把「出窍」幕换成人物专属母题）。
